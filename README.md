# Skin Cancer Prediction

## Project Overview
This project predicts different types of skin cancer using Deep Learning and medical image datasets. Users can upload skin images through a web interface and receive prediction results from the trained model.

---

## Features
- Skin cancer image classification
- Image upload through web interface
- Deep Learning model using TensorFlow/Keras
- Image preprocessing and normalization
- Prediction result display

---

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Flask
- HTML/CSS

---

## Dataset
The model was trained using medical image datasets for skin cancer classification.

## Output
The model predicts the skin cancer category based on the uploaded image.
